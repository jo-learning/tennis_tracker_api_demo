# Tennis Tracker API Demo

## Setting Up the Environment
1. **Create a Virtual Environment**  
    Use the following command to create a virtual environment:  
    ```bash
    python<version> -m venv <virtual-environment-name>
    ```
    Example:  
    ```bash
    python3 -m venv venv
    ```

2. **Activate the Virtual Environment**  
    Enter the virtual environment using the following command:  
    - On **Linux/macOS**:  
      ```bash
      source <virtual-environment-name>/bin/activate
      ```
    - On **Windows**:  
      ```bash
      <virtual-environment-name>\Scripts\activate
      ```

3. **Install Dependencies**  
    Activate the virtual environment and install the required packages:  
    ```bash
    pip install -r requirements.txt
    ```

## Running the Application

1. **Start the Application**  
    Run the following command to start the application:  
    ```bash
    python3 app.py
    ```

2. **View the Frontend**  
    Open `font2.html` in your browser to view the front page.

## Notes

- Ensure you have the correct version of Python installed.
- Replace `<version>` and `<virtual-environment-name>` with appropriate values.
